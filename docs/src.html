data-fx="draw"

Self-drawing line art

Any SVG illustration draws itself stroke by stroke when it scrolls into view. No measuring paths, no timeline to set up.

  • data-af-stagger seconds between strokes
  • data-af-duration seconds per stroke
<svg data-fx="draw" data-af-stagger="0.12">
  <path d="…" />
</svg>
data-fx="reveal"

Masked reveals

Headings rise out of a mask word by word, or letter by letter. Inline markup like em survives, and screen readers hear the full sentence once.

  • data-af-split words or chars
  • data-af-stagger seconds between pieces

data-fx="foil"

Foil text

A slow metallic sweep across type, like light moving over a foil-stamped invitation. Pure CSS, so it costs nothing to run.

  • --af-foil-shine highlight colour
  • --af-foil-deep shadow colour
  • --af-foil-speed one full sweep

Couture

<h1 data-fx="foil" style="--af-foil-shine:#f1d9a7">Couture</h1>
data-fx="spotlight" · data-fx="tilt"

Spotlight and tilt

A soft light follows the cursor through dark sections, and cards lean toward it with a slight magnetic pull. Combine effects by listing them in one attribute.

  • data-af-tilt max rotation in degrees
  • data-af-pull magnetic drift in px
  • --af-spot-color light colour

data-fx="curtain"

Curtain

A panel pulls away to unveil an image or video, which settles from a slight zoom. Runs on page load or when it scrolls into view.

  • data-af-direction up, down, left, right
  • data-af-trigger view or load
  • --af-curtain-color panel colour
<figure data-fx="curtain" data-af-direction="left">
  <img src="look-07.jpg" alt="…">
</figure>

Three ways in

From a CDN

Drop two tags in, and every data-fx on the page comes alive.

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/atelier-fx/dist/atelier-fx.min.css">
<script src="https://cdn.jsdelivr.net/npm/atelier-fx" defer></script>

With a bundler

Works with Vite, Next.js, Astro and anything that speaks ES modules.

import { init } from 'atelier-fx';
import 'atelier-fx/style.css';

init();

In React

A component and a hook that clean up on unmount.

import { FX } from 'atelier-fx/react';

<FX as="h1" fx="reveal">
  Every seam finished by hand.
</FX>

Building in Webflow, Framer, WordPress or Shopify? Paste the CDN tags into your head code and add data-fx as a custom attribute. Step-by-step guides

Kind to every visitor

Reduced-motion users see the finished page instantly. Touch devices skip cursor effects.

Nothing to fight

Effects add classes and CSS variables only, so your own styles stay in charge.

Fast by default

Only transforms and opacity animate, and nothing runs until it is on screen.
